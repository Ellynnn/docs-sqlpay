This release splits SOCSO contributions into Invalidity and Non-Employment Injury categories across reports, adds Hong Leong Connect Pro EIS format, Maybank2E-RC Payment Advice support, and fixes Hong Leong Connect First validation. (*244*)

<!-- truncate -->

## Features

- Added **Payment Advice** records support in **Maybank2E-RC Universal Payment** format (#6345)
- Added **Hong Leong Connect Pro** Excel format for **EIS** (#6333)

---

## Updates

- Split **Employee SOCSO** into **SOCSO (Invalidity)** and **SOCSO (Non-Employment Injury)** amounts in **Payroll Summary**, **SOCSO/EIS** report, **Payslip**, and **Yearly Individual** report (#6332, #6335)
- Revised script descriptions

---

## Bug Fixes

- Fixed invalid Validation ID Type for **DUITNOW** payment mode in **Hong Leong Connect First** format (#6337)

This release improves Time Attendance Summary and OT grid display, adds a Script column to the unassigned listing report, and fixes an access violation and missing employer SOCSO on the payslip summary. (*244*)

<!-- truncate -->

## Updates

- Revised **Time Attendance Summary** implementation
- Added **Script** column to **Time Attendance Unassigned Listing** report
- Revised **TMS OT Grid** to single-level grid
- [WebApp] Added **More** page to **Maintain Employee**

---

## Bug Fixes

- Fixed access violation error when applying leave on rest day or public holiday with special rate prompt
- Fixed **Payslip Summary** missing **SOCSO (Employer)** amount

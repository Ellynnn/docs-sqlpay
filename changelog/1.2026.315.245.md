This release resolves multiple SOCSO and EPF report calculation bugs, corrects CP22A date handling, and fixes TMS log duplicate record errors. (*245*)

<!-- truncate -->

## Bug Fixes

- Fixed `PR.Payslip1A.Report` YTD **SOCSO Employer** amount not correct
- Fixed **SOCSO (Invalidity)** and **SOCSO (Non-Employment Injury)** columns showing empty in **Payroll Summary** report when grouped by **Project**, **Job**, or **Task** (#6375)
- Fixed incorrect group footer subtotals for **SOCSO IV** and **SOCSO IJ** columns in **PR.Summary.Grouped-L3** report (#6369)
- Fixed incorrect **EPF** amount in paysheet when **Employee SOCSO borne by employer** master allowance is configured to contribute EPF (#6371)
- Fixed **Date From** columns in **Income Tax CP22A** format filled with the first day of the year when employee's join date falls later (#6370)
- Fixed **Maintain Leave Type** allowing both **Is Entitle** and **Is Unpaid** to be checked simultaneously (#6372)
- Fixed line breaks in email string when generating **Advice Type** record in **Maybank2E-RC Universal Payment** format
- Fixed company name registration check when switching on drive
